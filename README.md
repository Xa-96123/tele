# 影渠

从公开 Telegram 电影频道提取影视资源信息，去重后汇总成可搜索片库。

影渠读取 `https://t.me/s/<频道>` 网页预览（不需要 Bot Token），解析片名、年份、画质、体积、豆瓣/IMDb 和网盘/磁力链接，并跨频道合并同一部作品的多个版本。

本工具只做索引与汇总，不下载、不托管视频文件。请只添加你有权查看的公开频道，并遵守当地法律与版权规定。

## 能做什么

- 添加公开频道用户名，抓取最近几页帖子并解析
- 粘贴频道帖子原文导入（频道无法预览时）
- 按类型、年份、画质、来源、频道筛选
- 同一部影片的多频道版本合并到一张卡片
- 导出 JSON / CSV
- 首次打开带有演示片库，无需任何密钥

## 本地运行

需要 Node.js 20+。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43141](http://127.0.0.1:43141)。

```bash
npm test    # 解析与去重测试
npm run build
```

## 使用说明

1. 打开「频道」页，填入公开频道，例如 `https://t.me/s/some_movie_channel`。
2. 点击「提取并汇总」。成功后影片会出现在「片库」。
3. 若频道是私密的、没有网页预览，或当前网络访问不了 t.me：在 Telegram 里复制帖子，用「粘贴导入」。多条帖子用空行或 `---` 分隔。
4. 「再往前翻」会继续抓更早的帖子。

识别的常见格式包括：

```
《沙丘2》 Dune: Part Two (2024)
豆瓣 8.3
2160p BluRay 42.6GB
https://pan.quark.cn/s/...
```

也支持 `【剧集】…第一季`、动漫/纪录片关键词，以及夸克、阿里云盘、百度网盘、115、123、PikPak、磁力、ed2k 等链接。

数据保存在浏览器 `localStorage`，刷新不会丢失。

## 限制

- 只能读**公开**频道的网页预览，不能进私密频道或绕过 Telegram 登录。
- 每页大约 20 条，默认同步 3 页；更早内容请点「再往前翻」。
- 解析依赖帖子写法，纯文件名、无片名的广告帖会被跳过。
- 演示频道没有线上帖子，同步真实频道请换成实际的 `@username`。
